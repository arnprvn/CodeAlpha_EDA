# CodeAlpha Task 2: Exploratory Data Analysis (EDA)

## Objective
Inspect a retail sales dataset, assess data quality, summarize its distributions, and explore sales/profit patterns by category, region, and month.

## Dataset
`data/retail_sales_dataset.csv` contains 1,200 **synthetic** sample orders created for learning. It is not real company/customer data.

## Tools
Python 3.10+, Pandas.

## Run
```bash
pip install -r requirements.txt
python eda_analysis.py
```

## Outputs
The script prints the dataset shape, sample rows, data types, descriptive statistics, missing values, duplicate IDs, invalid dates, quantity checks, and group-level findings. It writes summary CSV files into `outputs/`.
