# Task 2 — Exploratory Data Analysis Report

## Aim
To understand the dataset structure, assess data quality, and identify patterns in retail orders.

## Questions
1. How many records and fields are present?
2. Are there missing values or duplicate order identifiers?
3. Which product category and region contribute the most sales?
4. How do sales vary by month?
5. What are the total sales, total profit, and average sales per order?

## Method
The Python script uses Pandas to read the CSV, convert order dates, inspect data types and descriptive statistics, validate missing values and duplicate IDs, and create category, region, and monthly summary tables.

## Interpretation
Use the generated output tables to identify the leading categories/regions and months. Treat any patterns as illustrative only because the dataset is synthetic. Correlation or group differences do not establish causation.

## Limitation
The dataset was generated for education. Real business conclusions require verified transaction data and clear definitions for profit, discounts, returns, taxes, and shipping.
